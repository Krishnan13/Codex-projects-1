# Personal Life Dashboard

This app is set up for **GitHub + Phone only**.

## For you (non-technical): how to use it

1. Open this repo on GitHub.
2. Wait for the **Deploy app to GitHub Pages** action to finish (green check).
3. Open the GitHub Pages app link.
4. On Android Chrome: menu → **Add to Home screen** / **Install app**.
5. Use the app from your home screen.

## Notes
- No paid hosting required.
- Your data is stored locally on your phone browser.
- Use in-app JSON backup export regularly.
